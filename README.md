## 2. เป้าหมายของแอป

ช่วยผู้ใช้วางแผน ติดตาม และวัดผลชีวิตในทุกมิติอย่างเป็นระบบ ทั้งสุขภาพ การงาน การเงิน และการพัฒนาตนเอง แทนที่การจดแยกกันหลายที่ (สมุด, ปฏิทิน, แอปธนาคาร, แอปออกกำลังกาย ฯลฯ) ด้วยแดชบอร์ดเดียวที่เห็นภาพรวมทุกด้านพร้อมกัน

## 3. โมดูลหลัก (Feature Modules)

### 3.0 เข้าสู่ระบบ / สมัครสมาชิก (Login / Register)
- เข้าสู่ระบบด้วยอีเมล + รหัสผ่าน หรือเข้าสู่ระบบด้วย **Google Sign-In** / **Sign in with Apple**
- สมัครสมาชิกด้วยชื่อ, อีเมล, รหัสผ่าน + ยอมรับข้อกำหนดการใช้งาน หรือสมัครผ่าน Google/Apple เช่นกัน
- ลิงก์สลับไปมาระหว่างหน้าเข้าสู่ระบบ/สมัครสมาชิก และลิงก์ "ลืมรหัสผ่าน?"
- ปุ่ม Sign in with Apple ใช้สไตล์ปุ่มดำมาตรฐานตาม Apple Human Interface Guidelines — จำเป็นสำหรับการส่งขึ้น App Store เพราะมีการเข้าสู่ระบบผ่านบุคคลที่สาม (Google) อยู่แล้ว

### 3.1 Dashboard (หน้าหลัก)
- สรุปความสำเร็จวันนี้ในรูปวงกลม % รวมทุกด้าน
- สถิติด่วน: วันต่อเนื่อง (streak), งานวันนี้, ความคืบหน้าการออมเดือนนี้
- การ์ดภาพรวมแต่ละโมดูล พร้อมแถบความคืบหน้าสีประจำหมวด
- ตัวอย่างตารางเวลาวันนี้ (3 รายการล่าสุด)

### 3.2 ออกกำลังกาย (Exercise)
- ตั้งเป้าหมายจำนวนครั้ง/สัปดาห์
- แผนออกกำลังกายรายวัน (วิ่ง, เวทเทรนนิ่ง, ว่ายน้ำ, เดินเขา ฯลฯ) พร้อมเช็คลิสต์เสร็จ/ไม่เสร็จ
- สรุปนาทีรวมและแคลอรี่ต่อสัปดาห์
- เพิ่มกิจกรรมออกกำลังกายเอง

### 3.3 ทานอาหาร & โภชนาการ (Nutrition)
- บันทึกมื้ออาหารรายวัน (มื้อเช้า / กลางวัน / เย็น / ของว่าง) พร้อม **เวลา** ของแต่ละมื้อ
- คุณค่าทางโภชนาการต่อมื้อ: พลังงาน (kcal), โปรตีน, แป้ง/คาร์โบไฮเดรต, ไขมัน, **น้ำตาล**, วิตามิน (A, B, C, D, E, K)
- สรุปรวมทั้งวันเทียบเป้าหมาย พร้อมเตือนเมื่อน้ำตาลเกินเพดานที่ตั้งไว้ และบอกวิตามินที่ยังขาดพร้อมตัวอย่างแหล่งอาหาร
- ติดตามการดื่มน้ำรายวัน (นับเป็นแก้ว แก้วละ 250 มล.) กดเพิ่ม/ลดได้ทีละแก้ว
- **เชื่อมกับการออกกำลังกาย**: เทียบพลังงานที่กินกับที่เผาผลาญวันนี้ (พลังงานสุทธิ), ดึงเวลาออกกำลังกายจากตารางเวลามาแสดง และเช็คว่ามีมื้อ "ก่อนออกกำลังกาย" / "หลังออกกำลังกาย" ครบหรือยัง พร้อมคำแนะนำปริมาณแป้ง/โปรตีนและน้ำที่ควรชดเชย

### 3.4 งานประจำ (Work)
- รายการงานแยกตามสถานะ: ต้องทำ / กำลังทำ / เสร็จแล้ว
- ระดับความสำคัญของงาน (ด่วน / งานประจำ / ทั่วไป)
- แถบความคืบหน้าของงานที่ใช้เวลานาน (เช่น รายงานรายไตรมาส)
- สรุปจำนวนงานรายวัน

### 3.5 ลูกค้า & ขายประกัน (CRM)
- เป้าหมายเบี้ยประกัน/ยอดขายรายเดือน พร้อมแถบความคืบหน้า
- สรุปตัวเลข: ลูกค้าใหม่ / นัดหมาย / ปิดการขาย
- รายชื่อลูกค้าที่ต้องติดตาม พร้อมสถานะ (ติดตามวันนี้ / รอตอบกลับ / ปิดแล้ว / ติดต่อกลับ)
- เพิ่มลูกค้าใหม่ / บันทึกการติดต่อ
- **รายงานผลงานประจำสัปดาห์ (P-A-S-R-F-N-T)** สำหรับส่งหัวหน้าและตามความคืบหน้าของงาน
  - P = Prospect, A = Appointment, S = Sales, R = Referal, F = Follow, N = New Market, T = Team
  - กรอกจำนวน + หมายเหตุของแต่ละตัวย่อ และเบี้ยประกันโดยประมาณของยอดขาย (S)
  - เลื่อนดูรายสัปดาห์ย้อนหลัง / เปิดรายการรายงานที่บันทึกไว้ทั้งหมด
  - ปุ่ม "คัดลอกส่งหัวหน้า" ได้ข้อความรายงานฉบับเต็มพร้อมวางในไลน์ทันที

### 3.6 การเงิน (Finance)
- สรุปรายรับ–รายจ่ายรายเดือน
- เป้าหมายการออม พร้อมแถบความคืบหน้าและยอดคงเหลือที่ต้องออมเพิ่ม
- สัดส่วนค่าใช้จ่ายแยกตามหมวด (อาหาร, เดินทาง, ลงทุน/ออม, อื่น ๆ)
- ประวัติรายการล่าสุด (รายรับ/รายจ่าย)

### 3.7 เรียนรู้ & พัฒนาตนเอง (Learning)
- สตรีคการเรียนรู้ต่อเนื่องรายวัน
- เส้นทางการเรียนรู้หลายสาย: ภาษาอังกฤษ, สกิลการลงทุน, คณิตศาสตร์, พัฒนาสมอง (brain training) — แต่ละสายมีแถบความคืบหน้าของตัวเอง
- บทเรียนถัดไปที่แนะนำ

### 3.8 ตารางเวลา (Schedule)
- มุมมองรายวัน (ไทม์ไลน์ตามเวลา) และรายสัปดาห์ (สรุปสถานะ 7 วัน)
- แต่ละกิจกรรมผูกสีตามหมวดชีวิต เพื่อดูภาพรวมความสมดุลของวันได้ในทันที
- เพิ่มกิจกรรม/นัดหมายใหม่

### 3.9 ความคืบหน้า & วัดผล (Progress)
- คะแนนรวมรายสัปดาห์ พร้อมกราฟแท่งเทียบ 7 วันและเทียบกับสัปดาห์ก่อน
- ความคืบหน้าแยกตามด้าน (% ของแต่ละโมดูล)
- Heatmap ความสม่ำเสมอย้อนหลัง 12 สัปดาห์
- ความสำเร็จ/เหรียญรางวัล (streak, เป้าหมายที่ทำถึง)

## 4. โครงสร้างการนำทาง (Navigation)

Bottom Navigation 4 แท็บ: **หน้าหลัก · ตารางเวลา · ความคืบหน้า · โปรไฟล์**

### 7.1 ฐานข้อมูล local (Hive)

- ทุก entity ใน `DATA_MODEL.md` เก็บเป็น `Map` ใน Hive box แยกตามโมดูล (`lib/data/hive_boxes.dart`) — ไม่ใช้ code-generated TypeAdapter เพื่อให้ปรับโครงสร้างข้อมูลต่อได้ง่าย
- แต่ละโมดูลมี repository ของตัวเอง (`lib/data/repositories/`) ให้ add / update / delete / getAll พร้อม `listenable()` สำหรับให้ UI รีเฟรชอัตโนมัติเมื่อข้อมูลเปลี่ยน
- ติดตั้งครั้งแรกจะ seed ข้อมูลตัวอย่างให้ (`lib/data/seed_data.dart`) เพื่อให้แอปดูมีเนื้อหาแทนที่จะว่างเปล่า จากนั้นข้อมูลทั้งหมดเป็นของจริงที่ผู้ใช้แก้ไขได้
- ตัวเลขในหน้า Dashboard และ Progress (`lib/data/insights.dart`) **คำนวณจากข้อมูลจริงในขณะนั้น** ไม่ใช่ค่าคงที่ — เช่น % ความคืบหน้าออกกำลังกาย = จำนวนครั้งที่ติ๊กเสร็จจริง / เป้าหมาย

### 7.2 ฟอร์ม/ปุ่มที่บันทึกข้อมูลได้จริงแล้ว

| โมดูล | การกระทำที่บันทึกจริง |
|---|---|
| เข้าสู่ระบบ/สมัครสมาชิก | สร้าง/บันทึกบัญชีผู้ใช้ผ่านอีเมล, Google, Apple (จำลอง — ยังไม่เชื่อม OAuth จริง) |
| ออกกำลังกาย | ติ๊กเสร็จ/ไม่เสร็จ, เพิ่มกิจกรรมใหม่ |
| ทานอาหาร & โภชนาการ | บันทึก/แก้ไข/ลบมื้ออาหารพร้อมสารอาหารและวิตามิน, กดเพิ่ม-ลดน้ำดื่มทีละแก้ว — สรุปรายวันและคะแนนโภชนาการคำนวณจากรายการจริง |
| งานประจำ | เพิ่มงาน, ติ๊กเสร็จ, ปัดลบ (swipe to delete) |
| ลูกค้า & ขายประกัน | เพิ่มลูกค้า, แตะเพื่อเลื่อนสถานะการขาย, กรอก/แก้ไขรายงานผลงานประจำสัปดาห์ P-A-S-R-F-N-T แล้วคัดลอกข้อความส่งหัวหน้า, เลื่อนดูสัปดาห์ย้อนหลัง |
| การเงิน | เพิ่มรายรับ/รายจ่าย พร้อมหมวดหมู่ — สัดส่วนค่าใช้จ่ายและเป้าออมคำนวณจากรายการจริง |
| เรียนรู้ & พัฒนาตนเอง | เพิ่มเส้นทางการเรียนรู้, กด "เรียนต่อ" เพื่อเพิ่ม % และนับสตรีครายวัน |
| ตารางเวลา | สลับมุมมองรายวัน/รายสัปดาห์, เลือกวันจากแถบ 7 วัน, เพิ่มกิจกรรมใหม่ (เลือกวัน + เวลาจริงผ่าน time picker), แตะกิจกรรมเพื่อแก้ไข (ทั้งสองมุมมอง), ลบจากปุ่มในฟอร์มหรือปัดซ้าย (ถามยืนยันก่อนลบ) |
| ล้างข้อมูล (โปรไฟล์ → สำรอง & กู้คืนข้อมูล) | "ล้างประวัติทั้งหมด" ลบข้อมูลที่บันทึกไว้ทุกโมดูลแต่คงบัญชี/เป้าหมาย/การตั้งค่าไว้ • "ล้างทุกอย่าง (รีเซ็ตแอป)" ลบหมดรวมบัญชีแล้วกลับไปหน้าเข้าสู่ระบบ — ทั้งสองแบบถามยืนยันพร้อมบอกจำนวนรายการที่จะลบ และข้อมูลตัวอย่างจะไม่กลับมาอีก |
| ตั้งค่าเป้าหมาย (โปรไฟล์ → ตั้งค่าเป้าหมาย) | แก้เป้าเงินออม, เป้ายอดขายเบี้ยประกัน, เป้าออกกำลังกาย/สัปดาห์ และเป้าโภชนาการต่อวัน (พลังงาน, โปรตีน, แป้ง, ไขมัน, เพดานน้ำตาล, น้ำดื่ม) — % ในหน้าการเงิน, CRM, ออกกำลังกาย, โภชนาการ, Dashboard, Progress คำนวณใหม่ทันที |

- **`flutter test`** — ผ่านทั้งหมด (46 tests): widget test หน้าตารางเวลา (สลับมุมมอง, แก้ไข, ลบพร้อมยืนยัน), สำรอง/กู้คืน, การคำนวณเวลาแจ้งเตือน, unit test ของทุก repository (`test/repository_test.dart`) ยืนยันว่า add/update/delete ผ่าน Hive ทำงานถูกต้องจริง รวมถึงเป้าหมายที่บันทึกไว้ถูกนำไปคำนวณ % ใน `Insights` + smoke test ของหน้า Login (`test/widget_test.dart`) และ widget test หน้าโภชนาการ (`test/nutrition_screen_test.dart`: แสดงมื้อ/สารอาหารของวันนี้, กดเพิ่มน้ำแล้วบันทึกจริง) + การ์ดโภชนาการบนหน้าหลัก (`test/dashboard_screen_test.dart`) และ widget test หน้าลูกค้า/รายงานสัปดาห์ (`test/crm_screen_test.dart`: แสดงตัวเลข P-A-S-R-F-N-T, เลื่อนสัปดาห์ย้อนหลัง, กดคัดลอกแล้วได้ข้อความรายงานเต็ม) และ test การล้างข้อมูลใน `test/backup_test.dart` (ล้างประวัติแล้วบัญชี/เป้าหมายยังอยู่, ล้างทุกอย่างแล้วออกจากระบบ, ข้อมูลตัวอย่างไม่กลับมาหลังล้าง)

### 7.4 Android SDK บนเครื่องนี้

ติดตั้งแบบ command-line tools เท่านั้น (ไม่ใช่ Android Studio เต็มรูปแบบ) ไว้ที่ `D:\android-sdk` พร้อม JDK 17 ที่ `C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot` ตั้งค่า environment variable (`ANDROID_HOME`, `ANDROID_SDK_ROOT`, `JAVA_HOME`) แบบถาวรไว้แล้ว มี AVD ชื่อ `lifeplan_avd` พร้อมใช้งาน (cache ของ Gradle/Pub/AVD ย้ายไปไว้ที่ D: — รายละเอียดและปัญหาที่เจอตอนติดตั้งดู `HANDOFF.md`)

### วิธีรันโปรเจกต์
```bash
cd lifeplan_app
flutter pub get
flutter emulators --launch lifeplan_avd   # เปิด emulator (ครั้งแรกบูตช้า ~1-2 นาที)
flutter run                               # เลือกอุปกรณ์ที่เชื่อมต่อ แล้วรันจริง
```
> Windows desktop build ยังต้องติดตั้ง Visual Studio "Desktop development with C++" workload เพิ่มถ้าต้องการ build เป็น .exe (ไม่จำเป็นสำหรับ Android/iOS/Web)
>
> iOS build ต้องใช้ macOS + Xcode ซึ่งเครื่องนี้ (Windows) ทำไม่ได้ — โค้ด Dart/Flutter เดียวกันนี้พร้อมสำหรับ iOS เมื่อ build บนเครื่อง Mac
